# Team LIDL

B2B sales intelligence for prioritizing companies across process automation, cybersecurity, and software development. The product connects configurable business questions to public evidence, explainable scores, and sales actions.

## Project status

48-hour hackathon, five contributors. This repository currently contains the execution documentation; application setup and implementation are next. Commands for running the application will be added with the initial scaffold.
